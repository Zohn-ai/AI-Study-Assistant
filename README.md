# StudyMate AI 🤖

StudyMate AI is a modern educational web application designed to make learning more interactive and personalized.

## Features

- 📚 Multiple subjects
- 🎯 Difficulty selection
- 📝 Interactive quizzes
- 🔀 Randomized questions
- 💡 Instant feedback
- 📊 Progress tracking
- 🏆 Final score
- 📱 Responsive interface

## Subjects

Currently available:

- Web Development
- Database
- Programming
- Artificial Intelligence

## Tech Stack

- HTML5
- CSS3
- JavaScript

No external frameworks or dependencies are required.

## How to Run

Simply open `index.html` in a modern web browser.

## Future AI Features

The project is designed as an MVP for future AI integration.

Planned features:

- AI-generated questions
- Personalized learning paths
- Adaptive difficulty
- AI explanations
- Weak-topic detection
- Personalized study recommendations
